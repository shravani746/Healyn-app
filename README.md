# Healyn — Smart Physiotherapy Monitoring

Healyn is an Android application designed to support physiotherapy exercises through computer vision and movement-based feedback. It helps patients perform selected exercises, monitor their performance, and receive corrective feedback during exercise sessions.

## Features

- **Exercise Selection:** Browse and select physiotherapy exercises.
- **Exercise Sessions:** Perform selected exercises while the application tracks body movements.
- **Pose Detection:** Use MediaPipe Pose to detect and track body landmarks.
- **Performance Feedback:** View exercise performance and feedback.
- **Real-Time Corrective Feedback:** Provide feedback messages based on detected movements.
